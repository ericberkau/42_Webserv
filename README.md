# Webserv

This project has been created as part of the 42 curriculum by eberkau, skomyshe, djanardh.

## Description
Webserv is an HTTP server written in C++.

The goal of this project is to understand how web servers work by implementing one from scratch. The server handles HTTP requests, processes them according to a configuration file, and sends appropriate HTTP responses to clients.

The project covers topics such as:

TCP/IP socket programming
Non-blocking I/O
Multiple client connections
Configuration and server setup
HTTP request and response handling
HTTP methods such as GET, POST, and DELETE
CGI execution
Error handling

## Instructions

### Requirements
C++ compiler supporting C++17
make

### Compilation
Clone the repository and run:
make

This creates the webserv executable.

To remove object files:
make clean

To remove all generated files:
make fclean

To recompile everything:
make re
