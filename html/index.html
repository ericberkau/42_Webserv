Webserv Playground

Try the server’s HTTP methods, file uploads, and CGI handlers from one page.

Each action sends a real request to this server. The response status and body appear below.

Static GET

Fetch a regular page or file served from the document root.

POST a message

Send a plain-text request body to the main route.

Upload a file

Uploads the selected file’s raw bytes to /upload/. Existing names are not overwritten.

Uploaded files

  • Choose Refresh to load the upload directory.

CGI GET

Run hello.py and pass a query parameter for the script to report.

CGI POST

Send text to cgi_testscript.py; its output echoes the request method and body.

Redirect

Open /redirect in a new tab. The server should respond with a 301 redirect.

Directory listing

Fetch /images/, where autoindex is enabled in the server configuration.

DELETE

Remove a file you uploaded. Use the Delete button next to a file after refreshing the list.
